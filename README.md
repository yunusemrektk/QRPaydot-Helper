# QRPaydot Helper — Restoran

QRPaydot Helper, kasa bilgisayarında çalışan küçük bir yardımcı uygulamadır: işletme panelinden gönderilen fişi LAN'daki termal yazıcıya iletir ve POS entegrasyonunu yürütür.

Bu repo yalnızca **dağıtım** içindir — kurulum dosyaları ve otomatik güncelleme manifestleri burada yayınlanır. Kaynak kod özeldir (private).

## İndir

**[QRPaydot.Helper.Setup.exe (son sürüm)](https://github.com/yunusemrektk/QRPaydot-Helper/releases/latest/download/QRPaydot.Helper.Setup.exe)**

Windows 10/11 · 64-bit. Kurulum bittiğinde Helper başlar; kontrol paneli: <http://127.0.0.1:17888>

Uygulama yeni sürümleri kendi kontrol eder ve arka planda sessizce günceller — tekrar indirmenize gerek yoktur.

## Diğer ürün

Stok yönetimi kullanan işletmeler farklı bir kurulum dosyası kullanır: **[QRPaydot-Helper-Stok](https://github.com/yunusemrektk/QRPaydot-Helper-Stok)**
